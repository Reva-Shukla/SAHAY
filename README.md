# SAHAY

**SAHAY** is a web-based mental health support platform designed to improve access to emotional well-being resources and facilitate communication between patients and counsellors.

The platform combines self-monitoring tools, wellness activities, and counsellor support through dedicated patient and counsellor interfaces.

## Features

**Patient Portal**
- Mood tracking, journaling, and wellness activities
- Personalised goals and progress monitoring
- Counsellor communication and meeting requests
- Emergency support resources

**Counsellor Portal**
- Patient case management and priority indicators
- Communication and meeting management
- Progress tracking and shared reports

**Additional Capabilities**
- English and Hindi language support
- Responsive interface
- AI-assisted support features under development
- Privacy-conscious, non-diagnostic design

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **UI & Visualisation:** shadcn/ui, Framer Motion, Recharts
- **Build Tool:** Vite
- **Routing:** React Router
- **Version Control:** Git, GitHub

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Reva-Shukla/SAHAY.git
cd SAHAY
```

Install dependencies and start the development server:

```bash
cd FRONTEND
npm install
npm run dev
```

Open the local URL displayed in the terminal.
